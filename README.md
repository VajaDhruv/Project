# AI Image Generator Website

A dynamic AI image generator website with a modern 3D visual look.

## Features
- Prompt-based AI image generation
- 3 output variations per prompt
- Aspect ratio selection (square, landscape, portrait)
- Optional seed input
- Live loading and resilient retry/error states
- Mouse-reactive 3D card effect

## Run
Open `index.html` directly in your browser.

For best compatibility, you can also serve it locally:

```bash
cd <project-directory>
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
